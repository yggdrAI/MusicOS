# DeepTrack AI Frontend

A modern, interactive dashboard for uploading songs and visualizing deep music analysis results.

## Features
- Drag-and-drop song upload
- Processing progress UI
- Interactive dashboard:
  - Waveform visualizer
  - Stem player
  - Lyrics viewer (with rhyme highlighting)
  - Beat & BPM display
  - Insights panel (genre, style, artist similarity, mood)

## Stack
- React + Next.js
- Tailwind CSS
- Framer Motion
- TypeScript

## Dev
- `npm install`
- `npm run dev`

## Test
- `npm run test`
